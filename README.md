# Drug-Recommendation-System-based-on-Sentiment-Analysis-of-Drug-Reviews
This project introduces a Drug Recommendation System designed to offer personalized drug suggestions by harnessing the collective experience and feedback found in user drug reviews.


This project delivers a Drug Recommendation System that leverages advanced Natural Language Processing (NLP) and Sentiment Analysis to provide personalized and context-aware medication recommendations. The system is designed to help users find suitable treatments by analyzing the real-world experiences and feedback of other patients with similar conditions.

Key Technical Focus
The core value of this system is its ability to transform qualitative user reviews into quantitative, actionable advice:

Sentiment Analysis for Advisability: The system uses sentiment scores derived from drug reviews to determine the perceived effectiveness and safety of a medication, directly assessing whether the drug is "advisable" for patients.

NLP Implementation: Review text is processed using the Bag of Words (BoW) model and various vectorization techniques to analyze linguistic patterns and extract meaningful insights.

Recommendation Generation: The system supports various recommendation methodologies, including Collaborative Filtering (based on similar user ratings), Content-Based Filtering (based on drug features), and Hybrid Approaches for maximum accuracy.

Project Methodology
The project followed a rigorous pipeline, beginning with gathering a comprehensive dataset from sources like Drugs.com and Kaggle, ensuring the data included crucial fields like Review Text, Drug Name, Condition, and User Ratings. The final, fully functional system is deployed using the Flask framework, making the recommendation engine operational and accessible.

This project showcases expertise in moving beyond simple data fitting to build an ethical, user-focused application at the intersection of machine learning and healthcare data.
